## 👋 About Me

I am a passionate Computer Science student and full-stack developer based in Siliguri, West Bengal, currently mastering the **MERN Stack**. I have hands-on experience building projects like **Laundrolink**, a **Library Management System**, and a **Visitor Pass Management System** using **Express.js** and **MongoDB**.

I thrive in project-based learning and enjoy solving complex problems through code. My focus is on creating efficient, scalable web applications while maintaining a strong foundation in software engineering. Beyond coding, I am an academic tutor, a dedicated gym enthusiast, and I'm currently learning **German** for my future master's journey in 2027 🚀
